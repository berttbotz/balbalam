# Checklist Android release

- [ ] Pastikan package ID `com.kickoffmanager.game` unik dan final.
- [ ] Set `CORS_ORIGIN` dan API URL ke backend HTTPS produksi.
- [ ] Tambahkan ikon, splash screen, nama aplikasi, versi, dan tautan dukungan.
- [ ] Uji pendaftaran, login, token kedaluwarsa, logout, sinkronisasi cloud, offline mode, dan pemulihan jaringan.
- [ ] Uji di beberapa ukuran layar dan perangkat Android.
- [ ] Tambahkan verifikasi email, reset password, penghapusan akun yang jelas, kebijakan privasi, dan kanal dukungan.
- [ ] Pastikan pengumpulan data dan praktik privasi dinyatakan secara akurat di Play Console.
- [ ] Buat signed Android App Bundle (AAB) untuk Google Play; APK signed dapat dipakai untuk distribusi langsung.
- [ ] Periksa target API, persyaratan akun pengembang, pengujian wajib, dan kebijakan Google Play yang sedang berlaku saat mengirim rilis.
- [ ] Periksa lisensi untuk database pemain, klub, logo, foto, liga, font, musik, dan aset pihak ketiga.
